# Arbeitsblätter

Der Pflichtweg verwendet die gekürzten Blätter zu **Perzeptron** und **mehrschichtigen Netzen**, jeweils mit Lösung. Das Memory zu den drei Lernarten findet ausschliesslich auf der Kursseite statt. Die zehn AVIVA-Abläufe mit Zeiten und Lernprodukten sowie die Lernziele stehen in `md/KI_Planung.md` und `md/KI_Lernziele.md`.

Regression und die älteren Prüfungsentwürfe liegen gekennzeichnet in `archiv/`. Sie gehören nicht zum aktuellen Pflichtweg. Der Leistungsnachweis ist das Tandemprojekt mit gemeinsamem Fachgespräch.

Markdown-Dateien liegen in `md/`. `./generate_pdfs.sh` erzeugt daraus PDFs; `--no-solutions` lässt Lösungsblätter aus. Benötigt werden Pandoc und eine LaTeX-Installation. In diesem Änderungsstand wurden die Markdown-Quellen überarbeitet; PDFs werden nicht eingecheckt.
