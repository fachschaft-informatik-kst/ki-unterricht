# Arbeitsblätter

Der Pflichtweg 2026/27 verwendet die gekürzten Blätter zu **Lernarten**, **Perzeptron** und **mehrschichtigen Netzen**, jeweils mit Lösung. Ablauf und Lernziele stehen in `md/KI_Planung.md` und `md/KI_Lernziele.md`.

Regression und die älteren Prüfungsentwürfe bleiben als Archivmaterial erhalten. Sie gehören nicht zum aktuellen Pflichtweg. Der Leistungsnachweis ist das Tandemprojekt mit gemeinsamem Fachgespräch.

Markdown-Dateien liegen in `md/`. `./generate_pdfs.sh` erzeugt daraus PDFs; `--no-solutions` lässt Lösungsblätter aus. Benötigt werden Pandoc und eine LaTeX-Installation. In diesem Änderungsstand wurden die Markdown-Quellen überarbeitet; PDFs werden nicht eingecheckt.
