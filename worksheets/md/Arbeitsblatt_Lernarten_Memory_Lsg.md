# Lösungen · Lernarten

1. Eingabe: Bildmerkmale der Karte; Label: vorgegebene Kategorie. Die gewählte Regel muss eindeutig sein. Menschen nutzen beim Sortieren Vorwissen; das Spiel ist eine Analogie, kein vollständiger Algorithmus.
2. Ähnlichkeit kann sich z.B. auf Farbe oder Motiv beziehen. Es gibt ohne vorgegebene Labels nicht zwingend eine einzige richtige Gruppierung. Die Gruppenzahl ist eine mögliche Modelleinstellung, keine notwendige Eigenschaft jedes unüberwachten Lernens.
3. Zustand: verbleibende Hölzer; Handlung: 1–3 nehmen; Rückmeldung: Sieg oder Niederlage. Verändert werden die bevorzugten Züge. Punkte allein würden noch nicht zeigen, wie sich eine Strategie anpasst.
4. Überwacht, unüberwacht, verstärkend. Das Bildprojekt nutzt beschriftete Beispiele und ist überwachtes Lernen.
