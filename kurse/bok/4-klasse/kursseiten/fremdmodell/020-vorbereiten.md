## Welche Dateien brauchen wir für die Prüfung?

<p class="section-intro">Halten Sie das <strong>fremde und das eigene Abgabe-ZIP</strong> sowie Ihre persönliche Gesprächszeit bereit. Mit dem fremden Projekt arbeiten Sie ausschliesslich in einem privaten Fenster.</p>

<p class="project-workplace"><strong>Werkzeuge für diese Etappe:</strong> <a href="#sicherung">Notizen &amp; Projekt</a> (ZIP wiederherstellen) · <a href="#projekt-werkbank">Journal &amp; Notebook</a>. Zurück zu dieser Doppellektion führt die Navigation: «Fremdmodell prüfen».</p>

<div class="dl8-section-head"><h3>Ihr Auftrag in 5 Schritten</h3><span class="dl8-meta">Im Tandem</span></div>
<ol class="dl8-steps">
  <li>
    <div class="dl8-step-top"><span class="dl8-step-num" aria-hidden="true">01</span></div>
    <h4>Eigenes ZIP zuerst entpacken</h4>
    <div class="dl8-step-copy"><p>Merken Sie sich die Fotostudio-JSON im Ordner <code>daten/</code>. Diese Datei brauchen Sie erst in <a href="#fremdtest">Etappe 3 (Eigene Bilder testen)</a>. Importieren Sie Ihr eigenes ZIP hier <strong>nicht</strong>.</p></div>
  </li>
  <li>
    <div class="dl8-step-top"><span class="dl8-step-num" aria-hidden="true">02</span></div>
    <h4>Fremdes ZIP entpacken</h4>
    <div class="dl8-step-copy"><p>Suchen Sie <code>Versuchsprotokoll.json</code> (Originalwerte) und die Fotostudio-JSON unter <code>daten/</code>.</p></div>
  </li>
  <li>
    <div class="dl8-step-top"><span class="dl8-step-num" aria-hidden="true">03</span></div>
    <h4>Privates Fenster öffnen</h4>
    <div class="dl8-step-copy"><p>Öffnen Sie darin die <a href="#fremdmodell">Kursseite DL 8</a> neu. Nur in diesem Fenster mit fremden Daten arbeiten. Ihr normaler Browserstand bleibt so unberührt.</p></div>
  </li>
  <li>
    <div class="dl8-step-top"><span class="dl8-step-num" aria-hidden="true">04</span></div>
    <h4>Fremdes Projekt wiederherstellen</h4>
    <div class="dl8-step-copy"><p>Öffnen Sie im privaten Fenster <a href="#sicherung">«Notizen &amp; Projekt»</a> und wählen Sie bei «Ganzes Projekt als ZIP sichern» <strong>«ZIP wiederherstellen ↑»</strong>. Wählen Sie das <strong>fremde</strong> ZIP. Die Wiederherstellung überschreibt ausschliesslich den Stand dieses Fensters.</p></div>
  </li>
  <li>
    <div class="dl8-step-top"><span class="dl8-step-num" aria-hidden="true">05</span></div>
    <h4>Notebook finden</h4>
    <div class="dl8-step-copy"><p>Öffnen Sie <a href="#projekt-werkbank">Journal → «Notebook hier öffnen»</a>. Dort liegt das importierte Projekt-Notebook. Es wird in <a href="#reproduktion">Etappe 2 (Daten &amp; Ergebnisse)</a> ausgeführt.</p></div>
  </li>
</ol>

<aside class="dl8-note"><span class="dl8-eyebrow">Datenschutz &amp; Sicherung</span><p>Achten Sie auf Datenrechte: Bilder anderer Tandems nur für diese Prüfung verwenden, nicht teilen und nach Vorgabe der Lehrperson löschen. Die ZIP-Wiederherstellung ist keine Abgabe.</p></aside>
