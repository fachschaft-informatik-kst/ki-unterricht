        <b>Überwachtes Lernen · mit richtigen Antworten</b>
        <p>Das System bekommt Trainingsbeispiele mit einer <strong>richtigen Bezeichnung (Label)</strong>. Es lernt, neue Beispiele einer der bekannten Klassen zuzuordnen.</p>
        <div class="learning-example-links">
          <a href="https://inf-schule.de/kids/computerinalltag/lernende-systeme/schritt2" target="_blank" rel="noopener noreferrer">Smiley-Spiel: fröhlich oder traurig? · inf-schule</a>
          <a href="https://quickdraw.withgoogle.com/" target="_blank" rel="noopener noreferrer">Quick, Draw! · Zeichnungen erkennen</a>
        </div>
        <div class="task">
          <p><strong>Erkundungsauftrag:</strong></p>
          <ol>
            <li>Zeichnen Sie im Smiley-Spiel zwei unterschiedliche Gesichter und lassen Sie sie erkennen. Notieren Sie eine richtige und eine falsche oder unsichere Zuordnung.</li>
            <li>Lesen Sie, mit welchen beschrifteten Beispielen das System vorher trainiert wurde. Welche beiden Labels kennt es?</li>
            <li>Probieren Sie in «Quick, Draw!» eine Zeichnung aus: Woran erkennen Sie, dass das System eine bereits gelernte Klasse vorhersagt?</li>
            <li>Erklären Sie, welche Rolle die richtigen Bezeichnungen der Trainingsbeispiele beim überwachten Lernen spielen.</li>
          </ol>
        </div>
        <p class="learning-example-note">Quick, Draw! kann Zeichnungen zu einem öffentlichen Datensatz beitragen. Zeichnen Sie keine Namen oder persönlichen Motive.</p>
