**Benötigt:** das von der Lehrperson zugeteilte *fremde* Abgabe-ZIP, Ihr *eigenes* Abgabe-ZIP und Ihre persönliche Gesprächszeit.

1. **Eigenes ZIP zuerst entpacken.** Merken Sie sich die Fotostudio-JSON im Ordner `daten/`. Diese Datei brauchen Sie erst beim <a href="#fremdtest">Fremdtest in Schritt 4</a>. Importieren Sie Ihr eigenes ZIP hier **nicht**.
2. **Fremdes ZIP entpacken.** Suchen Sie `Versuchsprotokoll.json` (Originalwerte) und die Fotostudio-JSON unter `daten/`.
3. **Privates Fenster öffnen.** Öffnen Sie darin die <a href="#fremdmodell">Kursseite DL 8</a> neu. Nur in diesem Fenster mit fremden Daten arbeiten. Ihr normaler Browserstand bleibt so unberührt.
4. **Fremdes Projekt wiederherstellen.** Gehen Sie im privaten Fenster zu <a href="#sicherung">Notizen &amp; Projekt → «Notizen &amp; Projekt wiederherstellen ↑»</a>. Wählen Sie das **fremde** ZIP. Die Wiederherstellung überschreibt ausschliesslich den Stand dieses Fensters.
5. **Notebook finden.** Öffnen Sie <a href="#projekt-werkbank">Journal → «Notebook hier öffnen»</a>. Dort liegt das importierte Projekt-Notebook. Es wird in <a href="#reproduktion">Schritt 3</a> ausgeführt.

<p class="small">Achten Sie auf Datenrechte: Bilder anderer Tandems nur für diese Prüfung verwenden, nicht teilen und nach Vorgabe der Lehrperson löschen. Die ZIP-Wiederherstellung ist keine Abgabe.</p>
