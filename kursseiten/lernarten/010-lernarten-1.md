<details class="kapitel" id="lernarten-1" data-kurz="Eingabe, Erfahrungsschatz, Ausgabe: Menschen schreiben Regeln oder Daten liefern sie." open><summary><span class="kapitel-nr">1</span><h2 class="kapitel-titel">Woher kommt die Regel?</h2></summary><div class="kapitel-body"><p>In <a href="#einstieg">Doppellektion 1</a> haben Sie zwei Wege kennengelernt, wie ein System zu seinen Regeln kommt: <strong>Menschen schreiben die Regeln auf</strong> (Schachprogramm mit festen Bewertungsregeln) oder das System <strong>lernt die Regeln aus Daten</strong> (Spamfilter). In Doppellektion 1 haben Sie gesehen, wie schwer es ist, die Regeln für «Katze auf einem Foto» von Hand aufzuschreiben. Die Grafik zeigt das <strong>EVA-Prinzip</strong>, nach dem jedes Programm arbeitet: <strong>E</strong>ingabe, <strong>V</strong>erarbeitung, <strong>A</strong>usgabe. Bei einem lernenden System kommt etwas dazu: der <strong>Erfahrungsschatz</strong>, das gespeicherte Wissen des Systems. Die Verarbeitung nutzt diesen Erfahrungsschatz, und neue Erfahrungen können ihn verändern.</p><div id="lernarten-intro"><figure class="concept-figure learning-system-figure"><img src="https://inf-schule.de/content/5_ki/1_menueansicht/1_basiswissen_ki/2_lernarten/2_erkundung_LernendeSysteme/evas.png" alt="EVA-Prinzip eines lernenden Systems: Eine Eingabe wird mit dem Erfahrungsschatz verarbeitet; die Ausgabe kann den Erfahrungsschatz erweitern." loading="lazy"/><figcaption>Ein lernendes System verarbeitet Eingaben mit seinem Erfahrungsschatz. Neue Erfahrungen können ihn verändern.</figcaption></figure><p class="small muted">In der Praxis können feste Regeln und Lernen aus Daten auch kombiniert werden.</p></div><label class="field answer"><span>Aufgabe: Erklären Sie die Grafik in einfachen Worten, so dass jemand sie versteht, der noch nie von KI gehört hat.
