### Druckvorlage: Zwei Saugroboter – Impuls für den Beamer (5 Min.)

| Roboter A | Roboter B |
|---|---|
| Fährt nach einem **festen Fahrmuster**. | Erstellt beim Fahren eine **Karte des Raumes**. |
| Wechselt die Richtung nach einer programmierten Regel. | Verwendet Kartendaten zur Navigation. |

**Diskussionsfrage:** Welcher Roboter ist intelligenter? Was müsste man wissen, um zu entscheiden, ob **gelernt** wird?

**Auflösung für die Lehrperson:** Kartenerstellung und Anpassung an eine neue Umgebung sind **nicht automatisch maschinelles Lernen**. Auch klassische Kartierungs- und Navigationsalgorithmen können ohne gelernte Gewichte arbeiten. Die Lernenden sollen zuerst begründen, nicht vom Gehäuse aufs Verfahren schliessen.

| Erste Regel | Gegenbeispiel |

Für Runde 2 Labels abdecken; für Runde 3 alle Karten verdeckt auslegen und die Paare suchen.

| | | | |
|:---:|:---:|:---:|:---:|
| ● | ▲ | ■ | ◆ |

**Beispiele für unüberwachtes Sortieren:** eckige / nicht eckige Formen; Himmelsmotive / andere; nach eigener begründeter Ähnlichkeit. Kein einziger Sortierschlüssel ist vorgeschrieben.

### Druckvorlage: Rollen und Beobachtungsbogen – Memory (15 Min.)

**Rollen (5 Lernende):** Agent · Kartenleitung · Beobachtung A · Beobachtung B · Zeit/Protokoll. Rollenwechsel **zwischen**, nicht innerhalb der Runden.

| Runde | Was erhält der Agent? | Was beobachten wir? |
|---|---|---|
| 1 · überwacht (4 + 1 Min.) | Acht Karten mit **Labels** als Beispiele | Welche Zuordnungen gelingt / misslingt? |
| 2 · unüberwacht (4 + 1 Min.) | Karten **ohne Labels** | Nach welchen Gemeinsamkeiten wird gruppiert? |
| 3 · verstärkend (4 + 1 Min.) | Verdeckte Paare; **+1** für Treffer, **0** für Fehlversuch | Verändert Rückmeldung das Vorgehen? |

**Wichtig:** Hier lernt ein **Mensch** als Agent. NIM zeigt anschliessend ein lernendes **digitales** System.

### Druckvorlage: Ein Lernschritt zum gemeinsamen Rechnen

**Neuron:** \(x_1 = 1\), \(x_2 = 1\); Gewichte \(w_1 = 0.2\), \(w_2 = 0.2\), Bias \(b = -0.5\). Schwelle 0; Lernrate \(0.2\). **Ziel: 1.**

1. Vorhersage: Summe \(1 \cdot 0.2 + 1 \cdot 0.2 - 0.5 = -0.1\) → Ausgabe **0**.
2. Fehler: Ziel − Ausgabe = **1**.
3. Korrekturregel: \(w_i \leftarrow w_i + 0.2 \cdot Fehler \cdot x_i\); \(b \leftarrow b + 0.2 \cdot Fehler\).
4. Neue Werte: \(w_1 = 0.4\), \(w_2 = 0.4\), \(b = -0.3\).
5. Neue Summe: \(0.4 + 0.4 - 0.3 = 0.5\) → Ausgabe **1**.

**Nachfrage:** Welche Zahlen hat das Neuron gelernt? Was an der Entscheidungsregel blieb gleich?

### Druckvorlage: Zwei Papier-Experimente (pro Gruppe)

**Satzanfang:** «Am Samstag gehe ich …»

**Runde A:** Nacheinander je **ein Wort** hinzufügen. Blatt nach jedem Zug so falten, dass nur die **letzten zwei Wörter** sichtbar sind. Bis ca. zwölf Wörter.

**Runde B:** Gleiche Regeln, aber **vier Wörter** bleiben sichtbar.

| Frage | Runde A – 2 Wörter | Runde B – 4 Wörter |
|---|---|---|
| Unser Text | | |
| Wo wird er unplausibel? | | |
| Welche Information fehlte? | | |

**Sicherung:** «Mit mehr sichtbarem Kontext …». Mehr Kontext bedeutet **nicht** automatisch Wahrheit.

### Druckvorlage: Ersatz bei Ausfall der Lernstrecke – Kontextvergleich

*Didaktisch erzeugtes Beispiel, **keine echte Ausgabe** aus Papagei oder Soekia:*

**Anfang:** «Die Astronautin öffnete die Luke. Draussen war …»

**Fortsetzung A (kurzer Kontext):** «… ein schöner Sommertag im Park.»

**Fragen:** Was passt zu welchem Kontext? Ist B zwingend **wahr**? Welchen Unterschied macht es, dass ein Wortfolge-System keine Quelle überprüft?
